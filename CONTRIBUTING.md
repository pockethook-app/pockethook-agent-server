# Contributing

Thanks for your interest in PocketHook agent server.

## Current status

This project is maintained as a personal open-source reference. **Pull requests are not being accepted right now** — I don't have the capacity to review and merge external contributions. This may change later.

## What you can do

### Open issues

Bug reports and questions are welcome. Please open an issue if you find:

- Something that doesn't work as documented
- A crash or unexpected behavior
- Unclear documentation

### Fork and customize

The repo is designed as a **starting point**, not a finished product — the [README](README.md) explains the `data/user/` overlay, custom tools, and user skills that let you customize without forking the framework code itself. If you do need deeper changes, fork freely (MIT license).

### Share what you build

If you build something interesting on top of this, feel free to link it in an issue.
